Cryptographic design
Will be basing the initial plan off Bitwarden

For key derivation, would look into PBKDF2 and Argon2id. 600 000 iterations are recommended for PBKDF2.

When I was researching Bitwarden, it seemed that encryption occured at nearly every step: transit with TLS, cloud storage encryption within Azure (Transparent Data Encryption), then additional layers by Bitwarden's server applications such as master password hashes. For data in transit, it uses an authentication hash derived from an email address and master password. The hash is generated in the originating device and then sent to the server.
